# Sterlin Glams — crawl rules
# Block the retired WooCommerce URLs (bots still crawl thousands of faceted
# /shop and /product-category permutations) and non-indexable app pages, so
# crawler traffic stops hammering the database. The live catalogue is /products.
User-agent: *
Disallow: /shop
Disallow: /product-category/
Disallow: /product/
Disallow: /cart
Disallow: /checkout
Disallow: /account
Disallow: /*filter_color=
Disallow: /*min_price=
Disallow: /*max_price=
Disallow: /*per_page=
Disallow: /*shop_view=
Allow: /products
